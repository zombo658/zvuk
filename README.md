# zvuk

Программа, которая повышает громкость всей системы — до **300%**. Обычное окно (фиолетовый стиль) плюс консольная утилита. Работает на Windows, Linux и macOS, внешние библиотеки не нужны — только Python 3.9+ (окно использует Tkinter из стандартной поставки).

## Программа с окном

```bash
python app.py
```

Ползунок 0–300%, кнопки ±10, пресеты 0/50/100/300. Горячие клавиши: стрелки вверх/вниз — ±5%, PgUp/PgDn — ±25%. Громкость, изменённая снаружи (клавишами ноутбука, микшером), подхватывается автоматически.

Если Tkinter вдруг не установлен (минимальные сборки Linux): `sudo apt install python3-tk`.

## Консоль

```bash
python volume.py            # прибавить громкость на 10%
python volume.py 25         # прибавить на 25%
python volume.py -25        # убавить на 25%
python volume.py --set 150  # установить ровно 150%
python volume.py --get      # показать текущую громкость
```

## Как это работает

| ОС      | Механизм                                          | Максимум |
|---------|---------------------------------------------------|----------|
| Linux   | `pactl` (PulseAudio/PipeWire)                     | **300%** |
| Linux   | `amixer` (ALSA, если нет pactl)                   | 100%     |
| Windows | WinAPI (`winmm.waveOutSetVolume`)                 | 100%     |
| macOS   | `osascript` (AppleScript)                         | 100%     |

Усиление сверх 100% умеет только звуковой сервер PulseAudio/PipeWire — на остальных платформах аппаратный предел микшера 100%, и значение аккуратно ограничивается. Осторожно: выше 100% возможны искажения звука и это громко.

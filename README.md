# zvuk

Управление громкостью всей системы — до **300%**. Есть веб-интерфейс (фиолетовый стиль) и консольная утилита. Работает на Windows, Linux и macOS, внешние библиотеки не нужны — только Python 3.9+.

## Веб-интерфейс

```bash
python server.py            # затем открой http://127.0.0.1:8000
python server.py --port 9000
```

Бэкенд — HTTP-сервер на чистой стандартной библиотеке, фронтенд — ползунок 0–300%, кнопки ±10 и пресеты. Если на машине нет звуковой подсистемы, сервер стартует в демо-режиме (громкость хранится в памяти).

### API

```
GET  /api/volume                  -> {"volume": 50, "max": 300, "backend": "pactl"}
POST /api/volume {"volume": 150}     установить громкость
POST /api/volume {"delta": 10}       изменить на N процентов
```

## Консоль

```bash
python volume.py            # прибавить громкость на 10%
python volume.py 25         # прибавить на 25%
python volume.py -25        # убавить на 25%
python volume.py --set 150  # установить ровно 150%
python volume.py --get      # показать текущую громкость
```

## Как это работает

| ОС      | Механизм                                          | Максимум |
|---------|---------------------------------------------------|----------|
| Linux   | `pactl` (PulseAudio/PipeWire)                     | **300%** |
| Linux   | `amixer` (ALSA, если нет pactl)                   | 100%     |
| Windows | WinAPI (`winmm.waveOutSetVolume`)                 | 100%     |
| macOS   | `osascript` (AppleScript)                         | 100%     |

Усиление сверх 100% умеет только звуковой сервер PulseAudio/PipeWire — на остальных платформах аппаратный предел микшера 100%, и значение аккуратно ограничивается. Осторожно: выше 100% возможны искажения звука и это громко.
